# 法律问答与引用评审

`legal-analysis` 是一套中文 Agent Skill，主要用于评审中国大陆和澳大利亚法律问答，也可以直接回答法律问题。提供 question 和 answer 时进入检查，citation 可选；只提供 question 或附有参考材料时直接回答。多题逐题选择模式。

评审分别说明主张是否成立、原引用支持什么，以及来源核验到了哪一步。原回答严重不足时，保留评审并给出完整重写的回答。直接回答与检查共用法域、时间、检索及依据核验规则。

## 安装

在准备评审问答的项目目录运行：

```sh
npx skills add HaaaappyDay/legal-analysis --skill legal-analysis
```

安装时可按提示选择你使用的 Agent。默认安装到当前项目；要在多个项目中使用，可在命令末尾加 `-g`。[skills CLI 安装说明](https://github.com/vercel-labs/skills#install-a-skill)

在线核验法源需要 Agent 具备网页搜索或读取能力，生成文件需要工作目录的写入权限。独立审查需要运行环境支持不继承历史的新上下文和文件交接；不具备时注明仅做同上下文复核，无法联网时标明材料分析与外部核验的边界。

## 试一道题

```text
请使用 legal-analysis 技能评审下面的问答，将报告保存为 legal-qa-review.md。

法域和时间：中国大陆，2023 年。
问题：我签了房屋买卖合同，还没办过户，合同有效吗？
原回答：房屋还没过户，买卖合同无效。
原引用：[1]《中华人民共和国民法典》第209条。
```

读报告时可以核对一个具体区别：第209条讲不动产物权变动的登记原则，原回答用它推断买卖合同无效。第215条直接涉及合同效力，应标为评审补充。报告应说明单凭未过户无法推出合同无效，并保留法律另有规定或当事人另有约定等条件。[《民法典》第209、215条](https://www.court.gov.cn/zixun/xiangqing/233181.html)

如果只需要直接回答，可仅提供上述问题、法域和时间，不附原回答；参考资料可以一并提供。[直接回答模板](references/answer-template.md)

默认直接回答写入当前工作目录的 `legal-answer.md`；含检查题的报告写入 `legal-qa-review.md`。同名文件已存在且未要求更新时使用递增后缀。多题保留题号，混合任务逐题使用对应结构并合为一份文件。已定位材料但只读到摘要时，标明“原文未核”。用户明确只要正文时按要求交付。[评审模板](references/report-template.md)

## 独立复核与文件交接

一般用户原回答由当前 Agent 检查；新生成或完整重写的回答交给不继承生成历史的独立上下文审查。涉及多法域、历史版本衔接或实质冲突等复杂事项时，先独立研究问题，再读取待审回答及引用对照。仅改笔误或引用格式时定向核对。

需要交接时，在 `.legal-analysis/` 下创建独立任务目录，以 UTF-8 文件保存原始问题、原回答、引用、各版草稿和审查结果。调度消息传文件路径、阶段和读写范围，正文不拼入工具调用或命令行。文件写完再交接，原始输入保持不变，草稿在审查期间冻结。共享文件系统不提供权限隔离，具体读取范围、两阶段顺序及降级方式见[复核与文件交接指南](references/review-workflow.md)。
