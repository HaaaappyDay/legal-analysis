# 劳动、产业关系、职业安全与工伤

| 事项 | 核引时应区分的判断 |
|---|---|
| 工资、劳动条件与解雇 | 查工作地点、雇主组织形式、雇用性质、适用工作关系体系、award 或 enterprise agreement。判断不公平解雇时分别审查申请资格、dismissal 是否发生、生效日期、申请期限及是否可延长。其他 general protections 或合同请求需单独找法源。[Fair Work Act 2009 (Cth)](https://www.legislation.gov.au/C2009A00028/latest/details) · [Fair Work Ombudsman 的覆盖说明](https://www.fairwork.gov.au/about-us/workplace-laws/fair-work-system) |
| 职业安全、工伤与平等保护 | 看监管辖区、风险控制主体、适用行业与地方采纳文本。职业安全义务、工伤法定给付、歧视或不利行动各有条件、期限和主管机关；查当地工伤计划和有关联邦或州反歧视立法。[Safe Work Australia 的示范法与当地采纳情况](https://www.safeworkaustralia.gov.au/law-and-regulation/model-whs-laws) |
| 集体协商、工会与产业行动 | 核实争议是企业协议谈判、协议批准、工会权利、工作场所代表权，还是受保护产业行动。分别查授权主体、程序、适用群体与命令。雇员受企业协议覆盖与某次行动具有法律保护，需要独立依据。[Fair Work Act 2009](https://www.legislation.gov.au/C2009A00028/latest/details) |

解雇同时涉及歧视时，结合[人权与反歧视](government-rights.md)核对投诉途径、并行程序限制和当事人所求救济。伤后领取福利或 NDIS 支持另查[社会保障](social-services.md)；养老金缴费见[税务与养老金](tax-super.md)。

**核引示例。** 用户给出 FWC 的期限说明，原答称“收到解雇通知即起算，错过绝无救济”。核查 *Fair Work Act* s 394(2)–(3)，区分通知日、解雇生效日与提交日，以及 exceptional circumstances 下的延长期限。若是否进入全国体系、雇用期或解雇性质尚不清楚，应保留相应条件；该条可以支持期限分析，对实体胜算仍需其他依据。[Fair Work Act 2009](https://www.legislation.gov.au/C2009A00028/latest/details) · [FWC 期限说明](https://www.fwc.gov.au/apply-or-lodge/deadlines)
