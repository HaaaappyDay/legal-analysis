# 刑事、争议解决与证据

先记下诉因或罪名、程序阶段、法院或 tribunal、相关文书与送达日期。州法院可以行使联邦管辖权；选择实体法、法院规则、证据法和上诉途径时应逐一说明各自依据。[高等法院的职能](https://www.hcourt.gov.au/about/overview-high-court/operation-high-court) · [各州和领地法例](https://www.opc.gov.au/links/legislation-states-territories-and-new-zealand)

| 争点 | 核对事实与法源 |
|---|---|
| 涉嫌犯罪、抗辩与刑罚 | 先识别 Commonwealth offence 或具体州、领地罪名。查行为时点、犯罪构成中的行为和主观要素、法定抗辩或例外、证明责任。联邦 *Criminal Code* 位于 *Criminal Code Act 1995* 的附表，不能凭此直接断定州罪名的构成。区分追诉、定罪、量刑和法定最高刑。[联邦 Criminal Code Act](https://www.legislation.gov.au/C2004A04868/latest/details) |
| 刑事程序与证据 | 保释、取证、可采性、陪审团指示、量刑和上诉各查相应程序；联邦案件在州法院审理时仍要核实有关程序法适用机制。警方指控、控方案情、证据可采与法院认定的证明门槛应分别表述。 |
| 民事责任与证明标准 | 引用 *Evidence Act 1995* (Cth) 前先查 s 4 的适用范围。在该法适用时，s 140 涉及民事证明，s 141 区分控方案情与辩方案情的法定标准，s 142 另就有关证据可采的事实作规定。另核对谁负举证或说服责任；其他法院应查当地证据法。[联邦 Evidence Act，ss 4、140–142](https://www.legislation.gov.au/C2004A04858/latest/details) |
| 民事诉讼、仲裁与执行 | 查适格原告与被告、管辖基础、州或联邦法院规则、程序阶段与时效，区分民事请求、特别法救济和 tribunal 程序。国内商事仲裁核对当地仲裁法与协议；国际仲裁查联邦法、仲裁地、执行及拒绝承认理由。[International Arbitration Act 1974 (Cth)](https://www.legislation.gov.au/C2004A00192/latest/details) |
| 上诉、许可与司法审查 | 区分对终局判决或中间命令上诉、是否需许可、能否质疑事实、何时起算及延长期限的权限。实践指引说明如何提交，法定上诉权另查授权法和法院规则。[联邦法院上诉管辖说明](https://www.fedcourt.gov.au/law-and-practice/appeals/from-courts/appellate-jurisdiction) |
| 跨境争议 | 分别查争点的准据法、管辖或仲裁条款、境外送达和证据、外国判决或仲裁裁决承认与执行。核实条约范围、实施法与适用国家或法院；合同选择某地法律，仅能直接回答相应选法争点。 |

**核引示例。** 用户问刑事定罪标准，原引 s 140。核实适用法院后，指出原条款针对民事程序；补充 s 141(1) 说明控方案情的标准。若争论特定证据能否采纳，继续核验 s 142 及对应可采性条款。逐项注明哪些说法正确而引文错误，哪些说法本身也需改写。[Evidence Act 1995 (Cth)](https://www.legislation.gov.au/C2004A04858/latest/details)
