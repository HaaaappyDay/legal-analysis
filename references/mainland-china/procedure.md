# 争议解决、程序与涉外事项

先固定用户要采取的行动，再确认当事人身份、受理机关、程序阶段、文书性质、送达方式及日期。分别评价受理条件、程序结果与实体请求。缺少起算事实时，说明计算方法和条件，暂不报出确定的最后一天。

| 问题 | 核验路径 |
|---|---|
| 民事诉讼与证据 | 核对主管管辖、诉讼主体、起诉、举证、证明标准、保全、审级、裁判种类及救济方式。上诉辨认判决或裁定、当事人住所和送达；时限逐一查起算、届满及顺延。另查民诉法司法解释与民事诉讼证据规定。[民事诉讼法（2023年修正）](https://ipc.court.gov.cn/zh-cn/news/view-6231.html) |
| 执行、异议及再审 | 核对生效法律文书、给付内容、履行期、申请执行期间及中止中断。辨明执行行为异议、案外人对标的异议及相应后续救济；申请再审的主体、法定事由和期间另行核验。 |
| 调解、公证、商事仲裁 | 核查协议或文书种类、是否具执行力、需要何种确认。商事仲裁先核查仲裁法版本、有效仲裁协议、事项可仲裁性和机构；再分辨撤销裁决、申请执行与不予执行。劳动仲裁和农村土地承包经营纠纷调解仲裁查各自特别法。[仲裁法修订施行信息](https://www.moe.gov.cn/jyb_xwfb/s6052/moe_838/202509/t20250915_1413498.html) · [劳动争议](social.md) |
| 行政复议与行政诉讼 | 核查行政行为、主体、受案范围、申请人与被申请人或被告、是否复议前置、期限、管辖和请求类型。复议法第23条列有先复议情形。复议决定、原行政行为以及机关不作为可能对应不同的诉讼问题。[行政复议法](https://hunca.miit.gov.cn/zwgk/zcwj/flfg/art/2024/art_719196b6d7e540dc8adbe8b009933b04.html) · [国家法律法规数据库，检索行政诉讼法](https://flk.npc.gov.cn/) |
| 国家赔偿与司法救助 | 国家赔偿先辨认行政赔偿、刑事赔偿或相关司法赔偿，查赔偿义务机关、法定事由、请求途径、损害及标准。法律援助、司法救助、行政补偿各自核查申请资格与主管机关。 |
| 涉外及跨法域 | 分别核查管辖、准据法、域外法查明、送达取证和判决或仲裁裁决的承认执行。依涉外民事关系法律适用法对每一争点定性，核实当事人选法是否允许及有无强制性规定。涉港澳台事项另查对应规则与司法协助安排。援引条约须核对缔约方、适用范围、保留声明、施行时间。[涉外民事关系法律适用法](https://wb.flk.npc.gov.cn/flfg/PDF/28487fc272234eddb41ba40d04d48188.pdf) |

**证明标准**　问题涉及民事待证事实时，先定谁承担证明责任。民诉法解释第108条涉及一般民事待证事实的高度可能性及反证，第109条对欺诈、胁迫、恶意串通等特定事实另作规定。因此，即使问答都用了“排除合理怀疑”一词，也应指出本题的程序、待证事项及对应条款。刑事定罪查[刑事程序](criminal.md)。[民诉法解释第108—109条](https://ipc.court.gov.cn/zh-cn/news/view-6228.html)

**评审示例**　用户问“我昨天收到行政罚款决定，必须先复议吗？”原回答只引用行政处罚法有关处罚权限的条文。原引可以支持“谁有权处罚”。就救济路径，需补充行政复议法第23条等，查是否当场处罚、是否另有前置规定，并核对救济告知及期限。罚款金额和送达日期单独不足以确定所有程序条件。[行政复议法第23条](https://hunca.miit.gov.cn/zwgk/zcwj/flfg/art/2024/art_719196b6d7e540dc8adbe8b009933b04.html)
