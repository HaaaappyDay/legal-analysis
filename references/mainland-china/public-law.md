# 宪法相关、行政监管与生态环境

先明确是谁对谁作了什么决定，用户要求确认权限、申请资格、履行义务、撤销决定还是赔偿。地域、层级、权限来源及程序节点常会改变结论。全国法律、行政法规、地方性法规和规章应定位到具体版本；属地办事要求到制定或实施机关核验。[国家法律法规数据库](https://flk.npc.gov.cn/) · [立法法](https://hubca.miit.gov.cn/zwgk/zcwj/flfg/art/2023/art_617433c825534c34a1104d67a6254ba2.html)

| 争点 | 法源和评审重点 |
|---|---|
| 基本权利、国家机构与监督 | 查宪法、立法法、组织法、选举法、监督法、监察法等相应规定。区分基本权利、机关职权、具体法定义务和个人可以使用的程序；讨论备案审查时核对对象、受理机关和提出方式。 |
| 国家安全、国防、国籍与出入境 | 依主体、地域及行为，查国家安全、保密、国防与兵役、国籍、出境入境管理及领事保护等相应规范。辨认主管机关、管辖及特别程序，区分义务、行政后果和犯罪构成。 |
| 行政许可、处罚、强制、征收与征用 | 分别核查权限、委托或授权、法定事由、程序、送达、期限和救济。罚款、行政拘留、查封扣押与行政强制执行须分别核对。行政指导或宣传材料不能独立证明有权处罚。[行政处罚法](https://www.119.gov.cn/gk/flfg/fl/2022/1045.shtml) · [行政强制法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2025/art_c5b6bfc45a5e45ca91b4a1ad2a1d2d93.html) |
| 信息公开、教育卫生、交通建设与公共安全 | 查政府信息公开条例及教育、卫生健康、道路交通、建筑、安全生产、消防、应急管理等特别规范。核对申请对象、服务或许可条件、法定答复方式和期限。行政处罚、行业纪律与民事赔偿分开评价。 |
| 土地、规划、农业与自然资源 | 查土地管理、城乡规划、农村土地承包、矿产资源、森林、水等相应规范及属地实施规则。识别权属性质、用途、审批或征收主体、公告、补偿对象与标准；财产归属并查[物权编](civil-code/property.md)。 |
| 生态环境与公益救济 | 依行为及损害时点，核对生态环境法典相关编章、民法典侵权责任编、特别规范及配套规则。区分民事赔偿、修复、公益诉讼、行政执法与刑事追诉的主体和要件。尤其查2026年8月15日前后持续行为、合同履行或时效届满情况。[生态环境法典施行信息](https://legalinfo.moj.gov.cn/pub/sfbzhfx/zt/2026zt0106/xxxcsthjfd20260817/yw20260817/202608/t20260817_538554.html) · [生态环境法典时间效力规定](https://www.court.gov.cn/zixun/xiangqing/508001.html) |

**评审示例**　引用某市办事指南回答“我在全国任意地方都能按这个标准领补助”时，原引只覆盖所列地域和事项。核对上位政策、授权和用户所在地区的当期实施文件，分别说明资格、金额和申请手续的依据。[行政救济与国家赔偿](procedure.md)
