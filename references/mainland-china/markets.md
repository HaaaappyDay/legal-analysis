# 市场交易、知识产权与经济监管

先分别写出用户要确定的民事权利、监管义务和程序。投诉是否受理、行政违法是否成立、消费者能否获赔是三个不同的命题。每个命题选能直接支持它的条款或裁判。

| 领域 | 检索起点 | 引用合理性检查 |
|---|---|---|
| 消费、产品、食品药品、电子商务 | 消费者权益保护法及实施条例、产品质量法、食品安全法、药品管理法、电子商务法和合同编 | 查购买目的、销售者、生产者及平台身份、产品缺陷或欺诈、标的类型及例外。退货、赔偿实际损失、惩罚性赔偿分别核验。 |
| 竞争、广告、价格 | 反垄断法、反不正当竞争法、广告法、价格法 | 鉴别垄断协议、滥用市场支配地位、混淆、商业秘密、虚假宣传等不同规则。投诉线索不能直接推出损害赔偿。核对行为所属期间的版本。[反不正当竞争法（2025年修订）](https://www.cnipa.gov.cn/art/2026/5/20/art_104_206437.html) |
| 著作权、专利、商标 | 著作权法、专利法、商标法、反不正当竞争法及配套规定 | 查作品或标识、权利归属、类别、保护期间、地域、权利要求范围及合理使用等抗辩。权利取得、民事侵权、行政授权确权和刑责要对应不同依据。 |
| 个人信息、数据、网络 | 个人信息保护法、数据安全法、网络安全法及配套规则；另读[人格权](civil-code/personality.md) | 识别处理者、信息主体、敏感性、目的、跨境和处理根据。回答称“一律须同意”时核对个人信息保护法第13条；有法定处理根据仍须核对告知、必要性等具体义务。[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm) |
| 银行、支付、投资、金融监管 | 商业银行法、反洗钱法、外汇和金融监管规定；金融产品另读[公司与商事](companies.md) | 区分资质、产品性质、监管禁止、合同效力、投资者损失与因果。查发文机关、适用机构及当时的监管规则。 |
| 财税、关税、海关、外贸与投资 | 预算法、税收征收管理法、具体税种法律、关税法、海关法、对外贸易法、外商投资法、出口管制法 | 核实纳税主体、交易或所得性质、所属期、计税基础、优惠资格、货物类别及进出口时点。属地答复和年度政策要对应具体地区及期间。 |
| 采购、招标、产业及行业准入 | 政府采购法、招标投标法、行业特别法、许可与强制性标准 | 查资金性质、采购人、项目范围、强制标准和公告；质疑、投诉、行政救济与民事争议各有条件和期限。 |

**评审示例**　“平台受到行政处罚，所以每一位购买者都可获三倍赔偿。”处罚决定可证明其载明的行政认定。评审仍须查消费者请求的依据、具体交易、欺诈等要件及赔偿计算基数；找到消费者权益保护法相关条款时，标明它补上的是民事请求的依据。[国家法律法规数据库](https://flk.npc.gov.cn/)
