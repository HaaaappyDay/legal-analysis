# 刑法与刑事程序

先确定被评价的是涉嫌犯罪、追诉条件、定罪、量刑，还是特定阶段的程序权利。题中举报、逮捕、起诉、定罪各有不同的事实基础。核验刑法、有关修正案及其时间效力、立法解释、司法解释与程序规范。[国家法律法规数据库](https://flk.npc.gov.cn/) · [刑事诉讼法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2025/art_48b3b0c3f954448e996602a71fc6f878.html)

| 争点 | 审查要点 |
|---|---|
| 刑法总则 | 确认行为时地、管辖、责任年龄与能力、主观要素、违法阻却事由、预备未遂或中止、共同犯罪与单位犯罪条件。跨修法案件定位行为时间、刑法第12条和相关解释；追诉时效另查。 |
| 刑法分则 | 按所指控罪名查对应章、条、款、项与司法解释。范围包括危害国家安全、危害公共安全、破坏社会主义市场经济秩序、侵犯公民人身权利民主权利、侵犯财产、妨害社会管理秩序、危害国防利益、贪污贿赂、渎职及军人违反职责等。金额或情节门槛须核对计算对象、地域与时点。 |
| 指控与证据 | 分别评价犯罪构成和支持事实的证据。核查公诉与自诉的证明责任、证据资格和排除规则、定罪所需证明标准。用民事裁判或行政认定支持定罪结论时，说明仍需查明的要件与证据。[刑事诉讼法第51、55条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2025/art_48b3b0c3f954448e996602a71fc6f878.html) |
| 强制措施、辩护与审判程序 | 区分侦查、审查起诉和审判阶段；确定当事人身份、有权机关、申请条件、期限起算与延长情形。未成年人等特别程序、自诉、刑事附带民事诉讼、上诉与抗诉另核对相应条文。[最高法刑诉法解释](https://www.court.gov.cn/zixun/xiangqing/286491.html) |
| 量刑与执行 | 按罪名、法定刑档、量刑情节和证据核验。自首、立功、累犯、认罪认罚、缓刑、数罪并罚各有条件。刑罚执行、减刑假释与社区矫正另查相应规范及阶段。 |

**评审示例**　“公司拖欠货款，因此负责人已经构成诈骗罪。”合同与付款证据可以支持民事履行情况。评审核对原答指向的罪名、主体、取得财产的方式及相应主观要素。事实不足时只指出需要查明什么；补充刑法条文可以解释要件，不能填补事实证据。[合同编](civil-code/contracts.md) · [国家法律法规数据库](https://flk.npc.gov.cn/)
