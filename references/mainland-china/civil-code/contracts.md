# 第三编　合同（第463—988条）

先找请求的法律后果。通则处理订立、效力、履行、保全、变更与转让、权利义务终止、违约责任；典型合同有各自的特别规则；准合同包括无因管理和不当得利。[民法典第三编](https://www.court.gov.cn/zixun/xiangqing/233181.html) · [合同编通则司法解释](https://www.court.gov.cn/zixun/xiangqing/419382.html)

| 问题 | 应核实的事实和对应规则 |
|---|---|
| 是否订立、某项条款是否约束双方 | 查要约承诺、实际履行、书面或电子证据。格式条款分别核查提示说明、是否成为合同内容、效力及解释（第496—498条）。民事行为效力并查[总则](general.md)。 |
| 能否要求继续履行、解除、索赔 | 区分约定和法定解除事由、行使方式与后果（第562—566条）；赔偿另查违约、因果、可预见损失、减损等（第577、584、591条）。请求违约金与定金要查实际约定、交付和适用关系。 |
| 谁有权向谁请求 | 转让债权、转移债务、加入债务、代位权、撤销权的条件各异。查通知对象、同意与否、到期和影响债权实现的事实。一般保证、连带责任保证还需分别核验约定、保证期间与权利行使。 |
| 哪类典型合同 | 按实质给付查买卖、供用电水气热力、赠与、借款、保证、租赁、融资租赁、保理、承揽、建设工程、运输、技术、保管、仓储、委托、物业服务、行纪、中介、合伙。建设工程特别核查资质和验收，租赁区分租期及维修，保理核对应收账款。混合交易说明哪项争点参照哪类规则。 |
| 没有合同也能否请求返还或偿还费用 | 无因管理查有无法定或约定义务、为谁管理、真实意思与必要费用（第979—984条）；不当得利查获益与受损、法律根据、受益人状态及例外（第985—988条）。仅有转账记录时须核实给付目的。 |

**评审示例**　回答称“交货晚一天就能解除”，原引第563条。条文与问题相关，但需查是否属于以迟延导致合同目的不能实现等法定事由；若主张迟延履行主要债务经催告仍未履行，还应核实催告及合理期限。另有解除条款时，将第562条标为评审补充，并说明还需核对约定内容。[民法典第562—566条](https://www.court.gov.cn/zixun/xiangqing/233181.html)

**司法实践｜软件交付逾期如何归责。** 入库参考案例 2023-13-2-146-003，二审案号（2019）最高法知民终433号。双方分头开发前后端，缺少共同确认的功能说明与进度计划，委托方人员更换且新增需求。二审维持驳回委托方诉请的判决。若回答只凭交付日期断定开发方违约，可用此案说明应查双方协作、变更记录与延误原因；有明确验收标准、需求稳定的题目需要另作比较。该案适用旧《合同法》，案例文本所列民法典条文是关联索引。[案例库文本，第2—3页裁判理由、裁判要旨与关联索引](https://ipc.court.gov.cn/upload/file/2025/12/01/15/30/20251201153032_81336.pdf)
